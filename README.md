# 🧠 REWIRE21

**Rewrite your habits in 21 days**

REWIRE21 is an open-source, privacy-first digital discipline app that helps you break phone addiction in 21 days.

## Features
- 21-Day Challenge
- Point Economy (1-6 hours/day)
- App Lock with Selfie
- Browser Lock (30-min cool-off)
- AI Companion
- 100% Private
